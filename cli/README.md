# Expenses CLI

Run `python expenses.py --help` to see usage.

- `--department`: Department to total (required).
- `--year`: Optional year to filter by.
- `--month`: Optional month to total: `Jan`, `Feb`, `Mar`, `Apr`, `May`, `Jun`,
  `Jul`, `Aug`, `Sep`, `Oct`, `Nov`, `Dec`.
- `--quarter`: Optional quarter to total (`1`–`4`).

Use `--month` or `--quarter`, not both.
